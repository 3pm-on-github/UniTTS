# StarTTS
General TTS bot with custom features

## Features
### Custom TTS Voices:
- Google TTS (25 Languages)
- SAM C64 (Custom Pitch, Speed, Mouth and Throat)
- Microsoft SAM (Custom Pitch, Speed)
### TTS if message contains prefix:
Example:
`$This will be played as TTS`
`This won't be played as TTS`
### Custom SFX:
`fish` plays a "fish" SFX.
